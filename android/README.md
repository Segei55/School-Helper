# School Helper - Android Project

Это нативный проект Android Studio для приложения "Школьный Помощник". Он использует `WebView` для отображения веб-версии приложения, добавляя нативные функции.

## Особенности
- **Скрытые ключи**: Ключи хранятся в `local.properties` (не попадает в Git) и передаются в приложение через `BuildConfig`.
- **Браузер и вкладки**: Внешние ссылки и авторизация Google открываются в системном браузере, а внутренние ссылки - внутри WebView.
- **Жесты**: Поддержка свайпа вниз для обновления (Pull-to-Refresh) и системной кнопки "Назад" для навигации по истории WebView.
- **Уведомления**: Настроен канал уведомлений. Веб-приложение может вызывать нативные уведомления через `window.AndroidNative.showNotification(title, message)`.
- **Deep Links**: Поддержка схемы `schoolhelper://` для возврата в приложение после авторизации.

## Как начать работу
1. Откройте папку `android` в **Android Studio**.
2. Скопируйте файл `local.properties.example` в `local.properties` и укажите ваши реальные ключи.
3. Дождитесь синхронизации Gradle.
4. Нажмите **Run** (Shift + F10) для запуска на эмуляторе или реальном устройстве.
5. Для сборки релизного APK перейдите в `Build` -> `Generate Signed Bundle / APK...`.
